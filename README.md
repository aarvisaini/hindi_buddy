# Hindi Buddy 🙏

A simple command-line quiz app to help you learn everyday Hindi words and phrases, with their English translations.

## What it does

- Greets you and asks for your name.
- Picks 5 random Hindi words/phrases from a built-in vocabulary list (greetings, common phrases, everyday nouns, etc.).
- Asks you to type the English translation for each one.
- Tells you immediately if you got it right, and gives the correct answer if you didn't.
- Shows your final score out of 5 at the end.

## Requirements

- Python 3

## How to use

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd hindi_buddy
   ```
2. Run the app:
   ```bash
   python3 main.py
   ```
3. Enter your name when prompted, then answer each Hindi word/phrase with its English meaning.
4. Run it again anytime to practice with a new random set of words.
